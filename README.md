# Zimba — Real Estate Experience

A mobile-first frontend concept for Uganda's property marketplace, featuring curated discovery, rentals and sales views, saved properties, detail dialogs, and an indicative construction cost estimator.

## Preview

Open `index.html` in a browser, or deploy through GitHub Pages.

## Deployment

A GitHub Actions workflow deploys `main` to GitHub Pages on every push. Repository admins may need to enable **Settings → Pages → Source: GitHub Actions** once.

## Current scope

This is an **interactive frontend prototype**, not a live property transaction platform. Listings are fictional demonstration entries and are explicitly labelled. Search/favorites operate locally, and favourites persist in localStorage. No database, authentication, payments or real inventory API is connected. The estimator uses illustrative values and should not be treated as a quotation.

## Production roadmap

1. Confirm brand, user journeys, content and design with project stakeholders.
2. Integrate verified listing database, property photos, agents, approvals, search and geolocation.
3. Add secure sign-in, agent dashboards, messaging, listing management and analytics.
4. Integrate professional cost estimator/BOQ, compliance review and partner onboarding.
5. Complete accessibility, security, privacy, end-to-end tests, SEO and performance optimization.

Project built as part of the AutoMinds Africa frontend modernization initiative.
